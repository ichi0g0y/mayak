# 分隊の共有（計画）

マップの分隊（[browser-shell.md](browser-shell.md#マップ)、[分隊ルーム](settings-and-integrations.md#分隊ルーム)）を、位置の共有から「分隊で見るものを共有する場所」に広げる計画です。まだ作っていない機能の仕様で、作ったところから各ページの説明に移し、ここからは消していきます。

## 作る順番

1. **自分のペン**: 済み（[browser-shell.md](browser-shell.md#自分のペン)）。
2. **サイドバーの分隊セクションと分隊ページ**: 済み（[browser-shell.md](browser-shell.md#分隊)）。分隊カラーも選べる。共有されたものの一覧と履歴は 4・5 で足す。
3. **分隊ペン**: 済み（[browser-shell.md](browser-shell.md#分隊ペン)）。中継（mayak-relay）も deploy 済み（2026-09-29）。
4. **Web タブの共有**
5. **スナップノートの共有**

## 済んだもの（残り）

自分のペン、分隊セクションと分隊ページ、分隊カラー、分隊ペンはできています（[browser-shell.md](browser-shell.md#マップ) の各節、[分隊ルーム](settings-and-integrations.md#分隊ルーム)）。そこから残ったことです。

- **共有されたもの**: サイドバーの分隊セクションの仲間の下に、共有されたもの（タブ、スナップノート、「○○ が Customs に描いています」）を新しい順に並べ、未読に点を付ける。分隊ページには履歴（種類で絞り込み）。4・5 で足す。
- **分隊カラーの決め方**: 今は中継の ID の順で決めている（つなぎ直すと ID が変わるので、取り合った色が入れ替わることがある）。報告にメンバー鍵が入ったので、メンバー鍵の順にできる。
- **つなぎ直しの間隔**: 今は 5 秒から 1 分まで延ばす（`internal/squad/client.go` の `run`）。レイド中に最大 1 分は長いので、上限を 15 秒にするか、Windows のネットワークが戻ったらすぐつなぐ。
- **スナップノートの分隊の線**: 今はレイヤー 2 に入れている。その時点の記録として画像に焼き込むほうがよいかは未決。
- **Client の線**: 計画では Client の線を Host が自分のメンバー鍵で出すはずだったが、Client も分隊の部屋に入っているので、Client 自身のメンバー鍵でそのまま描く形にした。Client の分隊カラーは、Host と同じ選んだ色（自動なら名前から）になる。

## Web タブの共有

- タブの右クリックメニューとツールバーに「分隊に共有」。送るのは URL とタイトルだけ（4096 文字に入る）。
- 受けた側では勝手にタブを開かず、サイドバーの分隊セクションに並べる。押すと開く（レイド中に邪魔をしない）。

## スナップノートの共有

- スナップノートに「分隊に共有」。
- 画像は分隊ルームの 1 件 4096 文字に入らない。分けて送ると上限 120 件 / 10 秒でも数百 KB に数秒〜数十秒かかる。暗号化した画像を中継に数時間だけ置く（R2 など）か、別の送り方を決めてから作る。

## 共有する内容の説明

今の説明（「共有するのは表示名と位置だけ」、`squadPrivacy`）は、機能を足すたびに直します。線、ペンの位置、共有したタブとスナップノートも、分隊コードで暗号化され中継には読めない、と書きます。
