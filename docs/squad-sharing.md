# 分隊の共有（計画）

マップの分隊（[browser-shell.md](browser-shell.md#マップ)、[分隊ルーム](settings-and-integrations.md#分隊ルーム)）を、位置の共有から「分隊で見るものを共有する場所」に広げる計画です。まだ作っていない機能の仕様で、作ったところから各ページの説明に移し、ここからは消していきます。

## 作る順番

1. **自分のペン**: 済み（[browser-shell.md](browser-shell.md#自分のペン)）。
2. **サイドバーの分隊セクションと分隊ページ**: 済み（[browser-shell.md](browser-shell.md#分隊)）。分隊カラーも選べる。共有されたものの一覧も済み。
3. **分隊ペン**: 済み（[browser-shell.md](browser-shell.md#分隊ペン)）。中継（mayak-relay）も deploy 済み（2026-09-29）。
4. **Web タブの共有**: 済み（[browser-shell.md](browser-shell.md#分隊への共有)）。
5. **スナップノートの共有**: 済み（同じ節）。中継は変えず、分隊の部屋で分けて送る形にした。

## 済んだもの（残り）

自分のペン、分隊セクションと分隊ページ、分隊カラー、分隊ペン、ページとスナップノートの共有はできています（[browser-shell.md](browser-shell.md#マップ) の各節、[分隊ルーム](settings-and-integrations.md#分隊ルーム)）。そこから残ったことです。

- **Client の線**: 計画では Client の線を Host が自分のメンバー鍵で出すはずだったが、Client も分隊の部屋に入っているので、Client 自身のメンバー鍵でそのまま描く形にした。Client の分隊カラーは、Host と同じ選んだ色（自動なら名前から）になる。

## これから

- **スナップノートを大きいまま送る**: 今は分隊の部屋で分けて送るので、300 KB で 10 数秒かかり、送ったときにいた人にしか届かない。中継に暗号化した画像を少しのあいだ置く形にすれば、速く、あとから入った人にも渡せる。
