# 分隊の共有（計画）

マップの分隊（[browser-shell.md](browser-shell.md#マップ)、[分隊ルーム](settings-and-integrations.md#分隊ルーム)）を、位置の共有から「分隊で見るものを共有する場所」に広げる計画です。まだ作っていない機能の仕様で、作ったところから各ページの説明に移し、ここからは消していきます。

## 作る順番

1. **自分のペン**: 済み（[browser-shell.md](browser-shell.md#自分のペン)）。
2. **サイドバーの分隊セクションと分隊ページ**: 分隊の管理をマップのパネルから移す。
3. **分隊ペン**: 同じマップに分隊の全員が同時に描ける。描いている途中とペンの位置も見える。
4. **Web タブの共有**
5. **スナップノートの共有**

## サイドバーと分隊ページ

- **サイドバーの「分隊」セクション**: ブックマークやスナップノートと同じ形（見出し、畳む、右端のボタン）。見出しに人数と接続の状態、右端のボタンで分隊ページを開く。
  - 上に仲間の一覧（色の点、名前、マップまたは「レイド外」）。押すとマップでその人に寄る（今の `squadFocus`）。
  - 下に共有されたもの（タブ、スナップノート、「○○ が Customs に描いています」）を新しい順に。未読に点を付ける。
  - 分隊に入っていないときは見出しと「作る / 参加」だけ。リリース版（`SquadAvailable` が false）では出さない。
  - ライブマップの行の人数（`squad-count`）はセクションと重なるので外す。
- **分隊ページ**: コード（伏せ字）、表示名、抜ける、最近の分隊、共有する内容の説明、共有されたものの履歴（種類で絞り込み）。
- **マップの分隊パネル**: 仲間の一覧だけに絞る（管理は分隊ページへ）。

## マップのペン

自分のペン（[browser-shell.md](browser-shell.md#自分のペン)、`map-draw.js`）はできています。分隊ペンはその横にもう 1 本のペンとして足し、道具の列・操作・座標（ゲーム座標でマップと階ごと、太さは画面上で一定）は同じにします。

- **道具**: 自分のペンと同じ列。消しゴム・元に戻す・すべて消すは、持っているペンの線にだけ効く。
- **分隊ペン**: 分隊に入っていないときは押せない。色は自分の印（矢印）と同じ色に固定し（色の選択は出さない）、線に乗ると描いた人の名前を出す。
  - 今の `memberColor` は名前から色を作るので、10 人だと近い色がぶつかり、名前を変えると色が変わる。分隊の中でぶつからないよう、参加の順などで割り当てる。
- **見分け**: 自分のペンの線と分隊の線が同じ地図に重なるので、分隊ペンを作るときに見分け方（自分のペンを少し細く・破線にする、など）を決める。
- **スナップノート**: 自分のペンの線はレイヤー 1 に入る（済み）。分隊の線はレイヤー 2 に各人の色のまま入れ、レイヤー 3 は書き足す用に空けておく。
  - 未決: 分隊の線はその時点の記録として画像に焼き込むほうがよいかもしれない。決まるまではレイヤーで作る。

## 分隊ペンの共有

### 決まり

- **消せるのは自分の線だけ**。消しゴムも元に戻すも自分の線にしか効かない。見ているものが人によって違うと話がかみ合わないので、人の線を自分の画面でだけ隠す機能も作らない。
- **全消去**: 「このマップの線を全員分消す」ボタンを 1 つ置く。押すと全員に「○○ が消しました」と出て、数秒だけ元に戻せる。
- **途中も見える**: 描いている途中の線と、分隊ペンを持っている人のペンの位置（名前付き）が全員に見える。

### メッセージ

分隊ルームのメッセージ（分隊コードの鍵で暗号化）に種類を足します。今の位置の報告（`Report`、`V: 1`）は変えません。古いアプリは開けないメッセージを捨てる（`openReport` が `V != 1` を捨てる）ので、位置の共有は壊れません。

| 種類 | 中身 | 使い捨て |
|---|---|---|
| 描き始め | 線の id、色、太さ、マップ、階 | はい |
| 途中の点 | 線の id、前回から増えた点（0.1 秒ごと） | はい |
| ペンの位置 | マップ、階、座標（ペンを持っている間、0.1 秒ごと） | はい |
| 線 | 線 1 本の全部（ペンを離したとき。これが正式な線） | はい |
| 消す | 線の id | はい |
| 全消去 | マップ、新しい世代、消した人 | はい |
| 同期の依頼 / 返事 | 下の「後から入った人」 | はい |

- 受け取った側は、描き始めと途中の点を仮の線として出し、正式な線が届いたら置き換える。正式な線が来ないまま数秒たった仮の線は消す（描いている人が落ちたとき）。
- 途中の点は、届いた間隔で少しずつ伸ばして描く（0.1 秒ごとでもぬるっと見える）。
- 線の id は描いた人が作る乱数。持ち主は下の「メンバー鍵」。

### 中継（relay）の変更

今の分隊ルームのままでは足りません（`relay/worker/index.js` の `SQUAD`）。

- **件数の上限**: 1 人 10 秒に 30 件では、描いている途中を送れない。超えると中継が切る（1008）。リンクのルームと同じ 10 秒に 120 件に上げる。
- **使い捨ての印**: 中継は各メンバーの最後のメッセージを後から入った人に渡す（位置のため）。途中の点などが最後の 1 件になると、後から入った人に位置が渡らない。暗号文の前に使い捨ての印（1 文字）を付け、印のあるメッセージは `member.last` にしない。中継に分かるのは使い捨てかどうかだけで、中身は読めない。
- **費用**: Durable Object は受けたメッセージの数で課金される。描いている間だけ 1 人 10 件 / 秒なので、増えるのは一時的。多ければ 0.15 秒ごとに下げる。
- 中継の deploy は、頼まれたときだけ行う。

### メンバー鍵

中継はつなぐたびに新しい乱数の ID を付けるので、線の持ち主をその ID で覚えると、つなぎ直した人は別人になり自分の線を消せなくなる。

- PC ごとに固定の「メンバー鍵」（乱数）を作って保存し、暗号化したメッセージの中に入れる。線の持ち主はメンバー鍵で覚える。
- Client の PC は分隊に直接つながらないので、Host のメンバー鍵で描く（下の「Client の PC」）。

### 世代（全消去）

- マップごとに世代（数）を持ち、線は描いたときの世代を持つ。全消去は世代を 1 つ進める。今の世代より古い線は出さない。
- 全消去を受けたら、そのマップの古い世代の線を捨てる。自分の線も捨てる（戻せる数秒のあいだは残しておく）。

### 後から入った人

中継は何も保存しないので、いる人が渡します。

1. 入った人は「今の線をください」（同期の依頼）を送る。
2. いる人はそれぞれ **自分の線だけ** を返す（マップごとの世代も付ける）。自分の線の消去や描き足しは同じ送り手から順に届くので、渡している最中に消えた線がよみがえらない。
3. 抜けた人の線（持ち主がいない線）は、中継の ID がいちばん小さい人がまとめて返す。全員が同じメンバー一覧を持つので、話し合わなくても決まる。3 秒で返事がなければ次に小さい人に頼む。
4. 1 件 4096 文字に入るよう、点は整数に丸めて差で持ち、短い線はまとめる。上限 120 件 / 10 秒なら、1 人数十本は 1〜2 秒で渡せる。
5. 描いている途中に入った人は、その線を描き終わりの正式な線から出す（途中の点は描き始めがないので出さない）。ペンの位置はすぐ見える。

### 落ちて戻ったとき

- **ほかの人の画面**: 落ちた人の線は残す。一覧に「切断中」と出し、線を少し薄くする。描いている途中だった線は仮の線なので数秒で消える。落ちているあいだの全消去では、その人の線も消える（世代）。
- **落ちた本人（アプリは動いたまま）**: 分隊ペンはそのまま描ける。描いた線は未送信としてためて、見た目で分かるようにする。途中だった線は、ペンを離したところで線になる。
- **落ちた本人（アプリが落ちた・再起動）**: 自分の分隊ペンの線を分隊コードごとにディスクに保存しておく（24 時間で消す）。起動すると今までどおり保存された分隊に入り直す（`api.js`）。途中だった線は捨てる。
- **戻ったときの順**:
  1. 同期を依頼し、いる人の線とマップごとの世代を受け取る。
  2. 落ちているあいだに全消去されたマップの自分の線を捨てる（先にしないと、消えた線がよみがえる）。
  3. 残った自分の線（ためていた未送信の線を含む）を送り直す。ほかの人の画面では、メンバー鍵が同じなのでその人の線として薄い表示が戻る。
- **全員が抜けたあと**: 各自が分隊コードごとに自分の線を保存しているので、24 時間以内に同じコードで集まれば、各自が送り直して線が戻る。
- **つなぎ直しの間隔**: 今は 5 秒から 1 分まで延ばす（`internal/squad/client.go` の `run`）。レイド中に最大 1 分は長いので、上限を 15 秒にするか、Windows のネットワークが戻ったらすぐつなぐ。

### Client の PC

- Client は分隊に直接つながらず、Host とのリンク（`squad:sync` と同じ道）で分隊の線を受け取る。つながったとき Host が今の線を全部渡す。
- Client で描いた線は、リンクで Host に送り、Host が自分のメンバー鍵で分隊に出す（同じプレイヤーなので、同じ色・同じ持ち主）。

## Web タブの共有

- タブの右クリックメニューとツールバーに「分隊に共有」。送るのは URL とタイトルだけ（4096 文字に入る）。
- 受けた側では勝手にタブを開かず、サイドバーの分隊セクションに並べる。押すと開く（レイド中に邪魔をしない）。

## スナップノートの共有

- スナップノートに「分隊に共有」。
- 画像は分隊ルームの 1 件 4096 文字に入らない。分けて送ると上限 120 件 / 10 秒でも数百 KB に数秒〜数十秒かかる。暗号化した画像を中継に数時間だけ置く（R2 など）か、別の送り方を決めてから作る。

## 共有する内容の説明

今の説明（「共有するのは表示名と位置だけ」、`squadPrivacy`）は、機能を足すたびに直します。線、ペンの位置、共有したタブとスナップノートも、分隊コードで暗号化され中継には読めない、と書きます。
