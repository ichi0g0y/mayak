MAYAK

Escape from Tarkov のスクリーンショットとログだけを読んで、マップ・タスク・アイテムをブラウザに同期するコンパニオン。ゲームのプロセスには一切触れません。

Windows 版をダウンロード すべてのリリース

macOS / Linux 版は受信専用クライアントとしてビルドしていますが、動作は未検証です。

できること

マップ上の位置を同期

スクリーンショットのファイル名に含まれる座標と向きを読み取り、tarkov.dev のマップ上のマーカーを動かします。マップはログから自動判定します。

タスク画面を認識

タスク一覧のスクリーンショットから選択中のタスク名をローカル OCR で読み取り、tarkov.dev や Wiki の該当ページを開きます。

アイテム情報を表示

アイテム詳細ウィンドウを撮るだけで、価格やトレーダー、必要なタスク・ハイドアウトをアプリ内のアイテム欄に表示します。

TarkovTracker と同期

EFT の通知ログからタスクの開始・失敗・完了を検知し、PvP / Season / PvE のプロフィールごとに TarkovTracker へ送ります。

レイドの通知

マッチ成立、レイド開始、ランスルー終了のタイマーをログから検知して、好きな音で知らせます。

自動アップデート

GitHub Releases の新しい版を自動で確認し、チェックサムを検証したうえで終了時に入れ替えます。日本語と英語の UI に対応。

使い方は 3 ステップ

  1. Remote ID を登録tarkov.dev のマップで Remote Control を有効にし、表示された ID を MAYAK に入れます。同じ PC のブラウザなら自動検出できます。
  2. フォルダを指定EFT の Screenshots と Logs フォルダを選びます。インストール先からの自動検出にも対応しています。
  3. ゲーム内で PrintScreenあとは普通に遊ぶだけ。保存されたスクリーンショットを MAYAK が検知して処理します。ゲームへの入力は送りません。

ゲームには触れません

MAYAK が読むのは、ゲーム自身が保存したスクリーンショットとログ、ローカルの設定ファイル、公開 Web API だけです。

  • プロセスメモリの読み取り、DLL インジェクション、フック、パケットキャプチャは行いません
  • ゲームへのキー入力・マウス操作の自動化は行いません
  • スクリーンショットはアップロードしません。OCR と画像解析はすべてローカルで実行します
  • TarkovTracker の API キーは Windows の DPAPI で暗号化して保存します
  • ソースコードは GPL-3.0 で公開しています

それでもコンパニオンツールの利用が許容されるかどうかはご自身の判断です。ゲームの利用規約を確認のうえ、自己責任でお使いください。

動作環境

  • Windows 11(WebView2 Runtime が必要。通常はインストール済み）
  • Escape from Tarkov のスクリーンショットとログのフォルダへの読み取りアクセス
  • OCR は同梱の Tesseract で動きます。Windows OCR を使う場合は英語の言語パックが必要です
  • インストーラーはありません。zip を展開して Mayak.exe を起動してください

ゲームデータは tarkov.dev、進捗は TarkovTracker の API を使っています。Escape from Tarkov は Battlestate Games の商標です。MAYAK は Battlestate Games、tarkov.dev、TarkovTracker とは無関係の個人プロジェクトです。
