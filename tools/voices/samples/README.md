# Voice samples

They are not built into MAYAK.

  "Match found." / "Raid started. Good luck." / "Run-through cleared. You can
  extract now." / "Welcome back. Check your quest items before the next raid." /
  "Couldn't identify the task.", in IMA ADPCM like the built-in voices.
